# פרק 3 — מודל נתונים ומסד נתונים

## 3.1 סקירה כללית

המערכת משתמשת ב-MongoDB — מסד נתונים NoSQL מסמכי. הנתונים מאורגנים ב-5 קולקשיינים (collections) עיקריים.

## 3.2 תרשים ER (Entity-Relationship)

```
┌──────────────┐       ┌──────────────────┐       ┌──────────────┐
│    Users     │       │   Transactions   │       │  Categories  │
│──────────────│       │──────────────────│       │──────────────│
│ _id (PK)     │◄──┐   │ _id (PK)         │   ┌──►│ _id (PK)     │
│ email        │   │   │ type             │   │   │ name         │
│ password     │   └──►│ created_by_id(FK)│   │   │ type         │
│ role         │       │ amount           │   │   │ color        │
│ created_at   │       │ category ────────┼───┘   │ budget_limit  │
└──────────────┘       │ description      │       └──────────────┘
                       │ merchant        │
                       │ date            │       ┌──────────────┐
                       │ receipt_url     │       │   Budgets     │
                       │ is_recurring    │       │──────────────│
                       │ tags[]          │       │ _id (PK)     │
                       │ notes           │       │ category     │
                       └──────────────────┘       │ amount       │
                                                  │ period       │
                       ┌──────────────────┐       │ start_date   │
                       │ RecurringPayments│       └──────────────┘
                       │──────────────────│
                       │ _id (PK)         │
                       │ created_by_id(FK)│
                       │ description      │
                       │ amount           │
                       │ category         │
                       │ type             │
                       │ frequency        │
                       │ next_execution   │
                       │ is_active        │
                       │ last_executed    │
                       └──────────────────┘
```

## 3.3 תיאור קולקשיינים

### 3.3.1 Users (משתמשים)

| שדה | סוג | תיאור | אילוץ |
|-----|-----|-------|--------|
| `_id` | ObjectId | מזהה ייחודי | PK, אוטומטי |
| `email` | String | כתובת אימייל | ייחודי, נדרש |
| `password` | String | סיסמה מוצפנת (bcrypt) | נדרש |
| `role` | String | תפקיד: `admin` / `user` | ברירת מחדל: `user` |
| `created_at` | Date | תאריך יצירה | אוטומטי |

### 3.3.2 Transactions (עסקאות)

| שדה | סוג | תיאור | אילוץ |
|-----|-----|-------|--------|
| `_id` | ObjectId | מזהה ייחודי | PK, אוטומטי |
| `created_by_id` | ObjectId | מזהה המשתמש הבעלים | FK → Users, נדרש |
| `type` | String | סוג: `income` / `expense` | נדרש, enum |
| `amount` | Number | סכום ב-₪ | נדרש, > 0 |
| `category` | String | קטגוריה | נדרש |
| `description` | String | תיאור מוצר / פעולה | נדרש |
| `merchant` | String | בית עסק | אופציונלי |
| `date` | Date | תאריך עסקה | נדרש |
| `receipt_url` | String | URL תמונת קבלה | אופציונלי |
| `is_recurring` | Boolean | האם מהוראת קבע | ברירת מחדל: false |
| `tags` | Array<String> | תגיות | אופציונלי |
| `notes` | String | הערות | אופציונלי |
| `created_date` | Date | תאריך יצירת הרשומה | אוטומטי |

### 3.3.3 Categories (קטגוריות)

| שדה | סוג | תיאור | אילוץ |
|-----|-----|-------|--------|
| `_id` | ObjectId | מזהה ייחודי | PK, אוטומטי |
| `created_by_id` | ObjectId | מזהה המשתמש הבעלים | FK → Users |
| `name` | String | שם קטגוריה | נדרש |
| `type` | String | סוג: `income` / `expense` | נדרש, enum |
| `icon` | String | שם אייקון | אופציונלי |
| `color` | String | צבע (hex) | אופציונלי |
| `budget_limit` | Number | מגבלת תקציב | אופציונלי |

### 3.3.4 Budgets (תקציבים)

| שדה | סוג | תיאור | אילוץ |
|-----|-----|-------|--------|
| `_id` | ObjectId | מזהה ייחודי | PK, אוטומטי |
| `created_by_id` | ObjectId | מזהה המשתמש הבעלים | FK → Users |
| `category` | String | קטגוריה | נדרש |
| `amount` | Number | סכום תקציב | נדרש |
| `period` | String | תקופה: `monthly` / `yearly` | ברירת מחדל: monthly |
| `start_date` | Date | תאריך התחלה | אופציונלי |

### 3.3.5 RecurringPayments (הוראות קבע)

| שדה | סוג | תיאור | אילוץ |
|-----|-----|-------|--------|
| `_id` | ObjectId | מזהה ייחודי | PK, אוטומטי |
| `created_by_id` | ObjectId | מזהה המשתמש הבעלים | FK → Users |
| `description` | String | תיאור | נדרש |
| `amount` | Number | סכום | נדרש |
| `category` | String | קטגוריה | נדרש |
| `type` | String | סוג: `income` / `expense` | נדרש |
| `frequency` | String | תדירות: `daily`/`weekly`/`monthly`/`yearly` | נדרש |
| `next_execution` | Date | תאריך ביצוע הבא | נדרש |
| `is_active` | Boolean | האם פעיל | ברירת מחדל: true |
| `last_executed` | Date | תאריך ביצוע אחרון | אופציונלי |

## 3.5 אינדקסים

```javascript
// Transactions
db.transactions.createIndex({ created_by_id: 1, date: -1 })
db.transactions.createIndex({ created_by_id: 1, category: 1, type: 1 })

// Categories
db.categories.createIndex({ created_by_id: 1, name: 1 }, { unique: true })

// Budgets
db.budgets.createIndex({ created_by_id: 1, category: 1 }, { unique: true })

// RecurringPayments
db.recurringPayments.createIndex({ created_by_id: 1, next_execution: 1 })
```
