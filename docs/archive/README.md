## תקציר מנהלים

**SmartHome** היא מערכת ניהול משק בית חכמה המאפשרת למשתמשים לנהל את ההוצאות וההכנסות שלהם, להגדיר תקציבים, לנהל הוראות קבע, ולהפוך קבלות וחשבוניות לעסקאות באופן אוטומטי באמצעות טכנולוגיית AI (OCR).

המערכת פותחה כאפליקציית ווב בטכנולוגיות מודרניות: React בצד הלקוח, Node.js/Express בצד השרת, ו-MongoDB כמסד נתונים. המערכת מאובטחת באמצעות JWT, הצפנת סיסמאות, ו-Row-Level Security המבטיח שכל משתמש רואה רק את הנתונים של עצמו.

### טכנולוגיות עיקריות

| שכבה | טכנולוגיה |
|------|-----------|
| Frontend | React 18, Vite, Tailwind CSS |
| Backend | Node.js, Express |
| Database | MongoDB (Mongoose) |
| Auth | JWT, bcrypt, OAuth (Google) |
| AI/OCR | LLM API (זיהוי קבלות) |
| Email | Nodemailer / SendGrid |
| Charts | Recharts |
