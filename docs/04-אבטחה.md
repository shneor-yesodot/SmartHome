# פרק 4 — אבטחת מידע

## 4.1 סקירה

אבטחת המידע היא עדיפות עליונה במערכת SmartHome, שכן היא מטפלת בנתונים פיננסיים רגישים של משקי בית. המערכת מיישמת הגנות במספר שכבות (Defense in Depth).

## 4.2 אימות והרשאות (Authentication & Authorization)

### 4.2.1 JWT — JSON Web Tokens

```
┌─────────┐     ┌─────────┐     ┌─────────┐
│ Login   │────►│ Server  │────►│ Token   │
│ (email+ │     │ verifies│     │ (JWT)   │
│  pass)  │     │ bcrypt  │     │ signed  │
└─────────┘     └─────────┘     └────┬────┘
                                     │
                                     ▼
                              ┌─────────────┐
                              │ Client stores│
                              │ token (httpOnly│
                              │ cookie/local) │
                              └──────┬──────┘
                                     │
                                     ▼
                              ┌─────────────┐
                              │ Every request│
                              │ Authorization│
                              │ Bearer <JWT> │
                              └─────────────┘
```

- **טוקן גישה (Access Token)** — תוקף קצר (15 דקות), מכיל user ID ו-role.
- **טוקן רענון (Refresh Token)** — תוקף ארוך (7 ימים), מאפשר חידוש.
- **חתימה** — HS256 עם מפתח סודי ממשתני סביבה.

### 4.2.2 הצפנת סיסמאות

```javascript
// יצירת hash לסיסמה
const salt = await bcrypt.genSalt(12);
const hashedPassword = await bcrypt.hash(password, salt);

// אימות סיסמה
const isMatch = await bcrypt.compare(inputPassword, user.password);
```

- **bcrypt** עם 12 rounds — מאט brute force.
- הסיסמה המקורית לעולם אינה נשמרת או נשלחת ללקוח.

### 4.2.3 OAuth 2.0 — Google

- התחברות דרך Google ללא צורך בסיסמה.
- קבלת פרטי משתמש מאומתים.
- טיפול מאובטח ב-redirect URIs.

## 4.3 Row-Level Security (RLS)

**זו שכבת האבטחה המרכזית להגנת פרטיות המשתמש.** RLS מבטיחה שכל משתמש יכול לקרוא, ליצור, לעדכן ולמחוק **אך ורק** את הרשומות שהוא עצמו יצר.

### כללי RLS לכל ישות

```json
{
  "rls": {
    "read":   { "created_by_id": "{{user.id}}" },
    "create": { "created_by_id": "{{user.id}}" },
    "update": { "created_by_id": "{{user.id}}" },
    "delete": { "created_by_id": "{{user.id}}" }
  }
}
```

| פעולה | כלל | משמעות |
|-------|-----|---------|
| **read** | `created_by_id == user.id` | משתמש רואה רק את הרשומות שלו |
| **create** | `created_by_id == user.id` | משתמש יכול ליצור רק רשומות על שמו |
| **update** | `created_by_id == user.id` | משתמש יכול לערוך רק את הרשומות שלו |
| **delete** | `created_by_id == user.id` | משתמש יכול למחוק רק את הרשומות שלו |

הכללים מופעלים ברמת השרת על כל בקשה — אי אפשר לעקוף אותם מהלקוח.

### ישויות מוגנות

| ישות | RLS | הערה |
|------|-----|------|
| Transaction | ✅ | עסקאות פרטיות לחלוטין |
| Category | ✅ | קטגוריות אישיות לכל משתמש |
| Budget | ✅ | תקציבים אישיים |
| RecurringPayment | ✅ | הוראות קבע אישיות |
| User | 🔒 | מנוהל ע"י הפלטפורמה (admins only) |

## 4.4 אבטחת HTTP

### 4.4.1 Helmet

```javascript
app.use(helmet()); // מוסיף headers אבטחה
```

Headers שמופעלים:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Strict-Transport-Security`
- `Content-Security-Policy`

### 4.4.2 CORS

```javascript
app.use(cors({
  origin: process.env.FRONTEND_URL, // מקורות מורשים בלבד
  credentials: true,
}));
```

### 4.4.3 Rate Limiting

```javascript
const limiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 דקות
  max: 100,                  // 100 בקשות מכל IP
});
app.use('/api/', limiter);

// הגבלה נוקשה יותר ל-login
const authLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5, // 5 ניסיונות התחברות
});
app.use('/api/auth/login', authLimiter);
```

## 4.5 ולידצית קלט

כל קלט מהלקוח עובר ולידציה באמצעות Joi לפני עיבוד:

```javascript
const transactionSchema = Joi.object({
  type: Joi.string().valid('income', 'expense').required(),
  amount: Joi.number().positive().max(1000000).required(),
  category: Joi.string().max(50).required(),
  description: Joi.string().max(200).required(),
  date: Joi.date().max('now').required(),
});
```

- מניעת SQL/NoSQL Injection
- הגבלת אורך שדות
- וידוא סוגי נתונים

## 4.6 אבטחת העלאת קבצים

```javascript
const upload = multer({
  storage: storage,
  limits: { fileSize: 10 * 1024 * 1024 }, // 10MB
  fileFilter: (req, file, cb) => {
    const allowed = ['image/jpeg', 'image/png', 'image/webp'];
    if (!allowed.includes(file.mimetype)) {
      return cb(new Error('סוג קובץ לא מורשה'), false);
    }
    cb(null, true);
  },
});
```

- הגבלת סוגי קבצים (תמונות בלבד)
- הגבלת גודל
- שמירה באחסון פרטי

## 4.8 סיכום איומים והגנות

| איום | הגנה |
|------|------|
| גישה לא מורשית לנתונים | RLS + JWT |
| גניבת סיסמה | bcrypt 12 rounds |
| Brute force | Rate limiting |
| XSS | Helmet CSP, sanitization |
| CSRF | SameSite cookies, tokens |
| Injection | Joi validation, Mongoose |
| קבצים זדוניים | multer fileFilter |
| חשיפת סודות | .env + .gitignore |
