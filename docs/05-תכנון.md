## 5.2 מקרי שימוש מפורטים

### UC-01: רישום משתמש חדש

| שדה | תוכן |
|-----|------|
| **שחקן** | משתמש אנונימי |
| **תיאור** | יצירת חשבון חדש במערכת |
| **תנאי מוקדם** | המשתמש אינו מחובר |
| **תנאי בסיסי** | רישום מוצלח ואימות אימייל |

**זרימה נורמלית:**
1. המשתמש נכנס לעמוד הרישום
2. מזין אימייל, סיסמה ואישור סיסמה
3. המערכת שולחת קוד OTP לאימייל
4. המשתמש מזין את הקוד
5. המערכת מאמתת ומחברת את המשתמש

**זרימות חלופיות:**
- 3a. אימייל כבר קיים → הודעת שגיאה
- 4a. קוד שגוי → אפשרות ניסיון חוזר
- 4b. קוד לא התקבל → שליחה חוזרת

### UC-02: הוספת עסקה

| שדה | תוכן |
|-----|------|
| **שחקן** | משתמש מחובר |
| **תיאור** | תיעוד הוצאה או הכנסה חדשה |
| **תנאי מוקדם** | משתמש מחובר, קיימות קטגוריות |
| **תנאי בסיסי** | העסקה נשמרת ומופיעה ברשימה |

**זרימה נורמלית:**
1. המשתמש לוחץ "עסקה חדשה"
2. בוחר סוג (הוצאה/הכנסה)
3. מזין סכום, קטגוריה, תיאור מוצר, בית עסק, תאריך
4. לוחץ "שמור"
5. המערכת בודקת חריגת תקציב → שולחת מייל אם חריגה
6. העסקה נשמרת ומופיעה בטבלה

### UC-03: העלאת חשבונית ופירוק לפריטים

| שדה | תוכן |
|-----|------|
| **שחקן** | משתמש מחובר |
| **תיאור** | העלאת תמונת חשבונית והפיכת כל פריט לעסקה |
| **תנאי מוקדם** | משתמש מחובר |
| **תנאי בסיסי** | נוצרות עסקאות נפרדות לכל פריט |

**זרימה נורמלית:**
1. המשתמש מעלה תמונת חשבונית
2. לוחץ "נתח חשבונית ב-AI"
3. ה-AI מזהה: בית עסק, תאריך, ורשימת פריטים
4. המשתמש עורך/מוחק/מוסיף פריטים
5. לוחץ "צור עסקאות"
6. המערכת יוצרת עסקה נפרדת לכל פריט
7. בודקת חריגות תקציב ושולחת מיילים

### UC-04: הגדרת תקציב וקבלת התראה

| שדה | תוכן |
|-----|------|
| **שחקן** | משתמש מחובר |
| **תיאור** | הגדרת תקציב חודשי וקבלת התראה בחריגה |
| **תנאי מוקדם** | משתמש מחובר |
| **תנאי בסיסי** | תקציב נשמר, התראה נשלחת בחריגה |

**זרימה נורמלית:**
1. המשתמש נכנס לעמוד תקציבים
2. לוחץ "תקציב חדש"
3. בוחר קטגוריה, מזין סכום, בוחר תקופה
4. שומר
5. כאשר הוצאות בקטגוריה עוברות את התקציב → מייל אוטומטי

### UC-05: יבוא עסקאות מ-Excel

| שדה | תוכן |
|-----|------|
| **שחקן** | משתמש מחובר |
| **תיאור** | יבוא מספר עסקאות מקובץ Excel/CSV |
| **תנאי מוקדם** | קובץ Excel תקין |
| **תנאי בסיסי** | כל העסקאות מיובאות |

**זרימה נורמלית:**
1. המשתמש לוחץ "יבוא Excel"
2. בוחר קובץ
3. המערכת קוראת ומנתחת את הקובץ
4. מציגה תצוגה מקדימה של העסקאות
5. המשתמש מאשר → יצירה גורפת
